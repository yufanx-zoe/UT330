Headings

Heading three

Heading four

Use them in order. Do not skip from h2 to h4 because you like the size better. Headings are how a screen reader user navigates the page, and how search engines work out what it is about. Change the size in CSS instead.

Text

A regular paragraph. Inside one you can have important text, emphasized text, a link, some highlighted text, an abbreviation you can hover over, a bit of inline code, deleted text, inserted text, and small print.

strong and em carry meaning. b and i only change appearance. Use the first two.

Form controls

You will not need these until later in the semester, but every one of them is something you will be redesigning.

Every input needs a <label> whose for matches the input's id. Without it, a screen reader announces an unlabeled box, and clicking the label text does not focus the field. Placeholder text is not a label.
